## 📖 Présentation du dépôt

Bienvenue dans mon dépôt consacré au cours **Administration Linux**.

Ce dépôt rassemble mes exercices, mes travaux pratiques et mes notes
d’apprentissage. Il permet de documenter les commandes utilisées,
les configurations réalisées et les résultats obtenus pendant les laboratoires.

## 🎯 Objectifs d’apprentissage

- Utiliser le terminal et les commandes essentielles de Linux.
- Créer et organiser des fichiers et des dossiers.
- Administrer les utilisateurs et les groupes.
- Configurer les permissions et les droits d’accès.
- Vérifier la configuration réseau.
- Comprendre le fonctionnement et l’administration d’un système Linux.

## 📚 Thèmes abordés

| Thème | Description | Exemples de commandes |
|---|---|---|
| Navigation | Se déplacer et repérer les fichiers | `pwd`, `ls`, `cd` |
| Fichiers et dossiers | Créer, copier, déplacer et supprimer | `mkdir`, `touch`, `cp`, `mv`, `rm` |
| Lecture des fichiers | Consulter le contenu des fichiers texte | `cat`, `less`, `head`, `tail` |
| Utilisateurs et groupes | Consulter et gérer les comptes | `whoami`, `id`, `useradd`, `usermod` |
| Permissions | Gérer les droits et les propriétaires | `chmod`, `chown`, `chgrp` |
| Réseau | Consulter les interfaces et tester la connexion | `ip addr`, `ping`, `ss` |
| Ressources système | Observer les processus, la mémoire et les disques | `ps`, `top`, `free`, `df`, `lsblk` |

## 🧪 Organisation des travaux pratiques

Chaque travail peut comprendre :

1. L’objectif du laboratoire.

3. Les commandes utilisées et leur rôle.
4. Les résultats obtenus.
